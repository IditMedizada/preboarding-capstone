# Project overview
This is a learning project: a Java 17 Spring Boot REST API for managing tasks.
Tasks are stored in memory using ConcurrentHashMap.

# Commands
Run these from the project root in Windows PowerShell.
Compile application code: .\mvnw.cmd compile
Run tests: .\mvnw.cmd test

# Rules
- Every new or modified endpoint needs a MockMvc test, run the tests before saying you're done.
- Do not commit or push unless I explicitly request it.
- Use the existing JUnit 5 and MockMvc setup.
- Format every code file you create or modify using the project's configured formatter.
